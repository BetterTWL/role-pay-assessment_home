## 🎨 1. 新粗野主義 (Neobrutalism) 視覺美學

極具張力的極客設計：首頁採用高對比的新粗野主義風格，搭配經典的工程網格背景（Blueprint Grid Layout），呈現出清晰的工程美學。
貼紙風格 LOGO (Sticker Style)：TWL 企業 LOGO 採用無模糊的邊框堆疊與純黑實體陰影，打造出極具觸感的「實體剪紙貼紙」效果，在深色背景下顯得俐落醒目。
無縫切換的雙主題模式：內頁提供 Light/Dark 雙主題按鈕，能自動透過 localStorage 記憶您的偏好。深色模式以精緻的碳黑色（Graphite Dark）作為主視覺，減少視覺疲勞，帶來尊榮且高質感的現代感。

## 📊 2. 即時動態職能雷達繪圖引擎 (Competency Radar Engine)

實時分數反映：結合 Chart.js 動態渲染，主管在評量表點選 0 到 3 分時，雷達圖會即時重新加權計算百分比，並滑順地動畫展現該職缺的「職能覆蓋得分」。
無縫配色感知：雷達圖的網格線、軸線與文字標籤，能偵測網頁主題切換，即時變更為高對比配色；同時移除傳統圖表刻度後方多餘的白色方形背景框，展現極簡且精緻的向量網格視覺。

## 🚨 3. 一票否決遙測面板 (Veto Clause Telemetry HUD)

合規風險預警：系統內置了針對各個職缺設計的「一票否決條款審查項目」（如 IATF 16949 等合規規範）。
即時遙測回報：主管評估時若勾選了任一否決項，右側 HUD 遙測數據面板會即時亮起紅色警示燈號，防止不合規的人員晉升或任用，確保內部評估的安全度與嚴謹性。

## 📈 4. 阿米巴經營效益動態模擬器 (Amoeba Simulator)

阿米巴核算公式整合：網站完整導入了阿米巴實體經營報表結構（銷售額分攤、外部費用、運作總工時等）。
參數即時試算：提供主管一個能夠任意調整數值的模擬器（Amoeba Simulator），即時算出工時附加值 (NTD/h) 及目標指標達標率，提供輔助經營與薪酬核定的科學數據。

## 📋 5. 政策政策與敏捷看板架構 (Kanban & Compliance)

敏捷任務看板 (Agile Kanban)：內建輕量化看板，用以展示受評者的具體待執行與已完成之任務，可視化追蹤人才培訓軌跡。
多維度標準比對：提供 IATF 16949 品質標準政策、用人政策對照、以及 104 HR 三層架構的資料庫快速對比，讓主管在同一介面中即可完成合規性審查。

## 📱 6. 雙端無縫同步 (Cross-Platform Responsive Sync)

專屬手機版介面：針對行動裝置開發了獨立的 /mobile 頁面，主管可透過首頁的 QR Code 一鍵開啟。
偏好共享：主題設定在手機與電腦版之間自動共享與記憶，雙端皆內建 Cache-Busting（版本快取清理）技術，確保即時載入最新樣式與交互功能。
